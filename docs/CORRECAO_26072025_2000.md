##  **PROBLEMA IDENTIFICADO**
```
TypeError: enviar_oferta_aiosteampy() takes 2 positional arguments but 3 were given
```

##  **CAUSA RAIZ**
A função `enviar_oferta_aiosteampy()` foi refatorada para receber apenas 2 parâmetros:
- **Antes**: `enviar_oferta_aiosteampy(client, tradelink, assetids)`
- **Depois**: `enviar_oferta_aiosteampy(steamid_destinatario, items_dict)`

Mas o código em `routes/trade.py` ainda estava chamando com a assinatura antiga.

##  **SOLUÇÃO IMPLEMENTADA**

### **Arquivo**: `routes/trade.py` (linhas 180-195)

**ANTES:**
```python
offer_id = await enviar_oferta_aiosteampy(client, tradelink, [item["assetid"] for item in itens_selecionados])
```

**DEPOIS:**
```python
# Preparar dados para a nova assinatura da função
items_dict = {
    "tradelink": tradelink,
    "items": [{"assetid": item["assetid"]} for item in itens_selecionados]
}

result = await enviar_oferta_aiosteampy(partner_steamid64, items_dict)

if result.get("success"):
    offer_id = result.get("tradeoffer_id")
    current_app.logger.info(f" Oferta enviada com sucesso! ID: {offer_id}")
    break  # Sucesso, sair do loop
else:
    # Se não foi sucesso, tratar como erro
    error_message = result.get("message", "Erro desconhecido")
    raise RuntimeError(error_message)
```
